# 주술결전 카드 듀얼

HTML 파일 하나로 실행되는 1:1 카드 배틀 게임입니다. (팬메이드 비공식 게임)

## 실행

- **사이트에서 실행 (GitHub Pages)**: 사이트 첫 화면의 [주술결전 카드 듀얼] 또는 `…/jjk_duel/` 주소로 엽니다. 게임 파일을 고칠 때는 PR → 머지만 하면 사이트에 반영됩니다.
- **파일로 실행**: `index.html`을 크롬·엣지에서 직접 열면 됩니다. 연습 대전·카드 설정·튜토리얼은 바로 쓸 수 있습니다.
- **온라인 대전**: 아래 [서버 배포](#서버-배포-apps-script) 방법으로 Apps Script 웹 앱을 배포한 뒤, 그 웹 앱 주소를 열면 게임이 실행되고 서버에 자동 연결됩니다. (또는 `index.html`의 [온라인 대전 → 서버 설정]에 웹 앱 주소를 입력)
- 휴대폰은 가로 화면을 권장합니다.

## 게임 모드

| 모드 | 설명 |
|---|---|
| QR로 친구 초대 | 버튼 한 번으로 방을 만들고, 친구가 휴대폰 카메라로 QR을 찍으면 바로 대전 |
| 연습 대전 | AI와 대전 |
| 온라인 대전 | 방 목록·방 코드로 참가. 난입·관전 차단, 턴 잠금, 턴 제한시간 60초 |
| 카드 설정 | 15장 이상으로 덱 구성 (같은 카드 중복 불가) |
| 튜토리얼 | 규칙, 궁극기 조합, 시너지, 마허라 소환 조건 |

## 주요 규칙

- 체력 80, 생명 2개. 본체 체력이 0이 되면 생명 -1 후 체력 회복
- 턴마다 메인 행동 1번(공격), 서브 행동 2번(뽑기·배치·마법)
- 필드: 메인(유닛) 1칸, 서브(서브·겸용 카드) 1칸, 대기 4칸
- 범위 공격은 상대 메인·서브 필드만 맞히고 본체는 맞히지 않음
- 궁극기: 해당 유닛 + 정해진 열쇠 캐릭터(서브 필드) + 촉매 마법
- 시너지 23종, 겸용 카드(유닛·서브) 16장
- 마허라: 항상 장착, 뽑기로 나오지 않으며 메구미 + 십종영법 식신 3종 + 생명 1개 조건에서 소환

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 게임 전체 (HTML/CSS/JS, 외부 이미지 없음, 효과음은 Web Audio API 합성) |
| `apps_script.gs` | 온라인 대전 서버 (Google Sheets + Apps Script) |

## 서버 배포 (Apps Script)

1. Google Sheets 새 스프레드시트 → 확장 프로그램 → Apps Script
2. `Code.gs`에 `apps_script.gs` 내용을 붙여넣기
3. 파일 + → HTML → 이름 `index` → `index.html` 내용을 붙여넣기
4. 배포 → 새 배포 → 웹 앱 (실행: 나, 액세스: 모든 사용자)
5. 수정 후에는 배포 관리 → 연필 → 새 버전으로 다시 배포 (주소 유지)

## 사이트(GitHub Pages)에서 온라인 대전

실시간으로 행동을 주고받는 일은 위의 Apps Script 서버가 맡고, 게임 화면은 사이트에서 엽니다. 게임 파일이 바뀌어도 서버는 다시 배포하지 않아도 됩니다.

1. 위 방법으로 Apps Script 웹 앱을 배포하고 주소(`https://script.google.com/macros/s/…/exec`)를 복사합니다. (3번 HTML 파일 추가는 생략해도 됩니다)
2. `index.html`에서 `const JJK_SERVER_URL='';` 줄의 따옴표 안에 그 주소를 넣고 PR → 머지합니다.
3. 이제 사이트에서 게임을 연 사람은 누구나 서버에 자동 연결됩니다. [QR로 친구 초대]의 QR을 찍으면 사이트의 게임이 열리고 그 방에 바로 참가합니다.

`JJK_SERVER_URL`을 비워 두어도, 방장이 [온라인 대전 → 서버 설정]에 주소를 넣어 두면 초대 QR에 서버 주소가 함께 담겨 친구는 설정 없이 참가할 수 있습니다.
