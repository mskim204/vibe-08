온라인 서버 설정 (Google Sheets + Apps Script)

온라인 대전은 구글 스프레드시트를 서버로 사용합니다. 한 사람만 아래 과정을 진행하고, 발급된 URL을 함께 대전할 친구와 공유하면 됩니다.

  1. Google Sheets에서 새 스프레드시트를 만듭니다.
  2. 메뉴 확장 프로그램 → Apps Script를 엽니다.
  3. 아래 코드를 Code.gs에 붙여넣고 저장합니다.
  4. 배포 → 새 배포 → 웹 앱 선택 · 실행 계정: 나 · 액세스 권한: 모든 사용자 → 배포 후 권한 승인
  5. 발급된 웹 앱 URL (…/exec)을 아래에 붙여넣고 저장합니다.
  6. (추천) 휴대폰에서도 하려면: Apps Script 왼쪽 [파일 +] → [HTML], 이름을 index로 만들고 이 게임 index.html 전체를 붙여넣은 뒤 [배포 관리 → 새 버전]으로 배포하세요. 그러면 웹 앱 URL을 여는 것만으로 게임이 실행됩니다.
