# 🍽️ 간식 투표 (구글 웹앱)

## 시트 준비
- **코드** 탭: A열에 투표 코드를 한 줄에 하나씩 적어요.
- **투표** 탭: 비워 두면 돼요. 투표하면 `시간 | 코드 | 선택` 이 자동으로 쌓여요.

## 설치 방법
1. 구글 시트에서 **확장 프로그램 → Apps Script** 를 열어요.
2. `Code.gs` 내용을 붙여 넣어요.
3. **파일 추가(+) → HTML** 로 `index`, `result` 파일을 만들고 각각 `index.html`, `result.html` 내용을 붙여 넣어요.
4. **배포 → 새 배포 → 웹 앱** 을 고르고
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
5. 나온 주소로 들어가면 투표 화면, 주소 끝에 `?page=result` 를 붙이면 결과 막대그래프가 나와요.

## 동작
- 코드 탭에 없는 코드 → "없는 코드에요"
- 투표 탭에 이미 있는 코드 → "이미 투표했어요"
- 처음 쓰는 맞는 코드 → 투표 탭에 저장
- 코드 확인은 모두 `Code.gs`(서버)에서 하고, 코드 목록은 화면으로 절대 보내지 않아요.
